Summary

The problem

Accessibility gaps
block work & revenue

Large enterprise organizations must provide accessible software for everyone. If Atlassian tools couldn't be used by people relying on screen readers, keyboard navigation, or other assistive tech, Atlassian would block efficiency as well as lose important enterprise customers.

The solution

Fix it now,
build it in for good

We remediated all issues for current customers so they wouldn’t churn. At the same time, we built a vision for how accessibility would be woven into every process and project lifecycle going forward, so we could win new customers in highly regulated fields.
