Summary

The problem

Accessibility gaps
blocked enterprise deals

Banks, financial bodies, and other regulated organizations must provide accessible software for everyone. If Atlassian tools couldn't be used by people relying on screen readers, keyboard navigation, or other assistive tech, Atlassian would lose important enterprise customers.

The solution

Fix it now,
build it in for good

We remediated all issues for current customers so they wouldn’t churn. At the same time, we built a vision for how accessibility would be woven into every process and project lifecycle going forward, so we could win new customers in highly regulated fields.

02 — VPAT Audit

many issues

By working in a deeply embedded fashion with product and engineering, our team remediated all critical issues within 9 months. This remediation consequently unblocked multiple enterprise deals, resulting in immediate revenue increase.

Where we focused firstThen, working down the list

Blocker

Very significant obstacles. Assistive tech users can't complete key tasks on core functionality.

Critical

Significant obstacles that frustrate or stop users, and can put the company at legal risk.

Serious

Some barriers, but people can still reach core content. Also carries legal risk.

Moderate

Lesser impact. A fix helps, but it doesn't stop anyone from using the product.

Minor

Bug-like or intermittent, hard to replicate. Fix only with a low-risk solution.

Assistive technology we interviewed on

  • Screen readers
  • Keyboard-only navigation
  • Screen magnification
  • Color-blind users

What we learned was problematic

  • Buttons and icons with no labels, so a screen reader only says “button”
  • Focus jumping around the page, or getting trapped in dialogs
  • Content clipped or overlapping when zoomed in
  • Status and errors shown by color alone

The Realization

04 — The Realization

Bugs weren't the problem — the system was

Fixing individual issues would only buy time. Internal and external customer research made the real pattern clear: without changing how we work, the gaps would just come back. Keeping them gone meant a complete overhaul of how we worked — and I led the design vision for it, grounded in what that research surfaced.

The Vision

06 — The Vision

From audit to embedded practice

The lasting outcome wasn't a one-time fix — it was a new way of working. We stood up a cross-functional accessibility team with shared rituals, tooling, and acceptance criteria, making accessibility a first-class input across design, build, and QA — not a late-stage audit.
